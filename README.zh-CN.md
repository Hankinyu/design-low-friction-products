# 低摩擦产品设计

[English](README.md) | 简体中文

这是一个用于设计和审查产品界面、表单、工作流、仪表盘及 AI 辅助操作的 Agent Skill。它采用一个简单的验收单位：用户能否从预期入口出发，以较低的学习成本，可靠地完成任务并获得明确结果？

当前状态：已正式开源的独立 Skill。首个版本是经过静态验证的最小英文运行包，并提供完整中文使用说明。

## 它重点保护什么

- 以短而完整的任务路径代替无边界的功能堆叠；
- 根据最近使用和高频记录改善选项顺序，同时避免不稳定或不安全的排序；
- 根据上下文提供智能默认值，并自动带入已确认的历史数据；
- 保护用户手动修改，不让自动带入或后台刷新悄悄覆盖当前输入；
- 让同一业务动作可以有多个便捷入口，但只保留一条权威的数据写入路径；
- 根据风险决定自动执行、确认、恢复和权限处理方式；
- 区分自动化检查、可用性审查与真实用户验收，不夸大验证结论。

这个 Skill 把“重复工作是否越来越省力”视为产品能力。它明确区分候选项资格、当前值保留、选项排序、推荐、自动带入与最终提交，避免一个用于提升便利性的信号在无意中替用户做出业务决定。

## 适用场景

当任务会实质改变用户可见的操作路径、表单行为、默认值、选项排序、流程自动化、异常恢复或多设备交互时，可以使用这个 Skill。典型场景包括：

- 让下拉选项优先展示最近使用或高频项；
- 自动带入上一次已确认的信息，减少重复录入；
- 缩短订单、审批、报销、客户跟进等业务流程；
- 审查“功能很多但越来越难用”的界面；
- 设计安全的 AI 建议、自动执行和人工确认边界。

纯后端重构、没有改变用户行为的文档修改，以及与实际任务无关的视觉调整，不需要触发这个 Skill。

## 安装

将可分发的 Skill 目录复制到支持的个人 Skill 位置：

```bash
mkdir -p ~/.agents/skills
cp -R skills/design-low-friction-products ~/.agents/skills/
```

Codex 通常会自动识别 Skill 变更；如果没有出现，请重启 Codex。

## 使用

可以显式调用：

```text
$design-low-friction-products 审查这个订单录入流程，减少重复输入并保护人工修改
```

当任务明显涉及用户操作流程、表单、默认值、选项排序、自动化、恢复机制或多设备交互时，Codex 也可以自动调用它。

## 仓库结构

```text
skills/design-low-friction-products/  可分发的英文运行包
evals/trigger-cases.json              中英文正向与负向触发案例
scripts/validate.py                   无第三方依赖的仓库校验脚本
README.zh-CN.md                       面向使用者的中文说明
```

运行包只维护英文权威版本，避免中英文两套执行规则逐渐产生行为差异；中文 README 用于理解和使用，不是第二份可执行 Skill。

## 验证

```bash
python3 scripts/validate.py
```

校验脚本会检查必要文件、frontmatter、包名、界面元数据、相对 Markdown 链接、公开引用是否使用 HTTPS、运行文件是否保持英文、常见私有路径与凭据模式，以及触发案例覆盖。

## 公开内容边界

这个公开仓库只包含通用设计模式和公开参考资料，不包含私人项目名称、本机绝对路径、客户信息、内部工作记录或无法公开核实的生产环境结论。
